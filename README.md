# Centre Informatique Universitaire — Website

This is a simple website for the Centre Informatique Universitaire (CIU), created as part of my web development learning journey. It introduces the center and showcases a few of its computer science courses.

## Features

- A welcome section introducing the center
- A section presenting courses in web development, computer networks, and artificial intelligence
- A visual contact form (it does not send messages)

## Technologies

- HTML5
- CSS3

## Open the project

1. Download or clone this repository.
2. Open the project folder in your code editor, such as Visual Studio Code.
3. Open `index.html` in a web browser.

## What I learned

Through this project, I practiced structuring a webpage with HTML, styling it with CSS, using CSS classes, and creating a contact form layout.
